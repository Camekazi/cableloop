# CableLoop

Landing page for a cable recycling and exchange platform concept. A design exercise in copper/forest colour palette with scroll-driven animations.

**Live**: [teamytastic.github.io/cableloop](https://teamytastic.github.io/cableloop/)

## What It Is

A single-page marketing site built as a frontend design exploration. Copper and forest green palette, noise texture overlay, custom easing curves, and smooth scroll navigation.

## Design Details

| Element | Choice |
|---------|--------|
| **Palette** | Copper (#B87333), forest (#1B4332), sage (#7C9A7E), cream (#F5F1E3) |
| **Typography** | Outfit (display) + IBM Plex Mono (accents) |
| **Texture** | CSS noise overlay on body |
| **Animation** | Custom easing: `ease-out-expo`, `ease-out-back` |
| **Navigation** | Fixed header with hide-on-scroll |

## Tech Stack

- **Framework**: Vanilla HTML/CSS/JavaScript — single file, zero dependencies
- **Fonts**: Google Fonts (Outfit, IBM Plex Mono)
- **Deployment**: GitHub Pages
- **Lines**: 1,849 (single `index.html`)

## Running

```bash
open index.html
```
